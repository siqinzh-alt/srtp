## 关键判断

- 三视图证明“幅频 + 相位差分 + 时频”比旧复合图略好，但 zero-shot 仍不是水声调制专家。
- BPSK 仍为 0%，说明当前相位差分图虽然人眼能看出跳变，但模型并没有把它理解为 BPSK；下一轮需要更强的相位表示或明确相位跳变任务。
- FSK 类型和 4FSK 仍为 0%，说明 VLM 可以在已知 FSK 的情况下识别 2FSK，但无法主动把 FSK 从 CW/LFM 中分出来，也数不出 4 个频阶。
- 250 Hz 仍为 0%，说明固定 `0-8000 Hz` 对低频读数不够，幅频图没有解决低频坐标读数问题。
- 三视图降低了 LFM 方向准确率，可能是 prompt 要求综合三图后反而稀释了纯时频斜率线索。

## 建议下一步

1. 不要直接微调当前三视图；先做输入表示消融，否则微调会掩盖表示问题。
2. BPSK 单独测试：把相位差分图改成“相位跳变强度/检测后的跳变脉冲图”，或增加带通后的相位差分版本。
3. FSK 单独测试：增加瞬时频率曲线或频率轨迹骨架图，让频阶数量变成一维阶梯而不是让模型从时频热图里数。
4. 主频单独测试：增加 `0-1000 Hz` 低频放大图，专门验证 250/500 Hz 混淆。
5. LFM 保持纯时频图路线，或在三视图 prompt 中对 LFM 方向只要求看第三行，避免其他视图干扰。
