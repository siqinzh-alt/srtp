# Qwen2.5-VL Zero-shot Probe Report

生成时间：2026-09-30 23:35 CST

## 实验设置

- 模型：`Qwen/Qwen2.5-VL-7B-Instruct`
- 任务性质：zero-shot 基模能力测试，不参与训练或微调
- 输入形式：每条音频生成一张复合图，包含波形、幅度谱、线性频率时频图
- 数据规模：126 条探针信号，222 条选择题评测项
- 对比基线：`Qwen/Qwen2-Audio-7B-Instruct` 直接吃音频的 zero-shot 结果

## 总体结果

| 模型 | 正确数 | 总数 | 准确率 |
| --- | ---: | ---: | ---: |
| Qwen2-Audio | 71 | 222 | 31.98% |
| Qwen2.5-VL | 130 | 222 | 58.56% |

结论：把信号显式转成“波形 + 频谱 + 时频图”后，VLM 的 zero-shot 表现明显优于 audio-only 基模，尤其是主频和 LFM 方向判断。

## 按任务对比

| 任务 | Qwen2-Audio | Qwen2.5-VL | 观察 |
| --- | ---: | ---: | --- |
| 信号类型识别 | 31/126 = 24.60% | 61/126 = 48.41% | VLM 能识别 CW 和部分 LFM，但把 BPSK/FSK 大量判成 CW |
| 主频选择 | 9/36 = 25.00% | 28/36 = 77.78% | VLM 可以直接读频谱峰，验证了“主频本应可见”的判断 |
| LFM 升/降频 | 18/36 = 50.00% | 29/36 = 80.56% | VLM 能读时频轨迹，降频仍弱于升频 |
| FSK 阶数 | 13/24 = 54.17% | 12/24 = 50.00% | VLM 全部 4FSK 误判为 2FSK，频阶计数仍不可靠 |

## 按噪声强度

| 噪声条件 | Qwen2-Audio | Qwen2.5-VL |
| --- | ---: | ---: |
| 无噪声 | 27/74 = 36.49% | 50/74 = 67.57% |
| 真实轻噪声 | 23/74 = 31.08% | 47/74 = 63.51% |
| 真实重噪声 | 21/74 = 28.38% | 33/74 = 44.59% |

结论：真实重噪声会明显拉低 VLM 表现，但 VLM 在三档噪声下都显著高于 audio-only。

## 按传播条件

| 传播条件 | Qwen2-Audio | Qwen2.5-VL |
| --- | ---: | ---: |
| Direct | 37/111 = 33.33% | 66/111 = 59.46% |
| Bellhop | 34/111 = 30.63% | 64/111 = 57.66% |

结论：当前 Bellhop 多径对 VLM 的总体影响不大；direct 与 Bellhop 准确率只差约 1.8 个百分点。

## 关键错因

- 信号类型：VLM 对 `CW` 极强，36/36 全对；但 `BPSK` 0/30、`FSK` 0/24，全部被判成 `CW`。
- LFM：升频 18/18 全对；降频 11/18，主要错成升频。
- FSK 阶数：2FSK 12/12 全对；4FSK 0/12，全部错成 2FSK。
- 主频：1000/4000/6000 Hz 全对，2000 Hz 5/6；低频端 250 Hz 2/6、500 Hz 3/6，说明低频峰或坐标读数仍会混淆。

## 初步判断

- 对“主频能不能从图上看出来”的问题，答案是可以：VLM 主频 77.78%，远高于 Qwen2-Audio 的 25.00%。
- 对“信号能不能直接认出来”的问题，答案是部分可以：CW/LFM 有可用迹象，但 BPSK/FSK 类型识别还不行。
- 后续不应马上微调；更应该先优化 zero-shot 评测输入图和 prompt，尤其是让图上明确展示相位跳变、瞬时频率轨迹、FSK 离散频阶。

## 建议下一步

1. 生成更适合 VLM 的诊断图：增加相位曲线、瞬时频率曲线、局部放大时频图。
2. 对 BPSK 单独做相位跳变选择题，验证 VLM 是否能读相位而不是只看频谱。
3. 对 2FSK/4FSK 单独做“频率轨迹中有几个离散频率”的题，验证频阶计数能力。
4. 保留 audio-only 与 VLM 两条路线：audio 模型可能更适合端到端微调，VLM 更适合先做可解释能力探针。
