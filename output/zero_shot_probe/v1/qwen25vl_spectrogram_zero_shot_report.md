# Qwen2.5-VL Spectrogram-only Zero-shot Probe Report

生成时间：2026-10-01 00:58 CST

## 实验设置

- 模型：`Qwen/Qwen2.5-VL-7B-Instruct`
- 任务性质：zero-shot 基模能力测试，不参与训练或微调
- 输入形式：只输入同一段信号的线性频率时频图，不再输入波形和幅度谱
- 图像设置：`0-8000 Hz` 线性频率轴，主刻度间隔约 `500 Hz`，带水平网格线
- 数据规模：126 条探针信号，222 条选择题评测项
- 结果文件：`qwen25vl_spectrogram_predictions.jsonl`、`qwen25vl_spectrogram_summary.json`

## 总体对比

| 输入/模型 | 正确数 | 总数 | 准确率 |
| --- | ---: | ---: | ---: |
| Qwen2-Audio，直接音频 | 71 | 222 | 31.98% |
| Qwen2.5-VL，复合图 | 130 | 222 | 58.56% |
| Qwen2.5-VL，纯时频图 | 126 | 222 | 56.76% |

结论：纯时频图总体略低于复合图，但主频与 LFM 方向更强；损失主要来自信号类型识别，说明“只看时频图”会削弱 CW/FSK/BPSK 的类型区分。

## 按噪声强度

| 噪声条件 | Qwen2-Audio | Qwen2.5-VL 复合图 | Qwen2.5-VL 纯时频图 |
| --- | ---: | ---: | ---: |
| 无噪声 | 27/74 = 36.49% | 50/74 = 67.57% | 50/74 = 67.57% |
| 真实轻噪声 | 23/74 = 31.08% | 47/74 = 63.51% | 38/74 = 51.35% |
| 真实重噪声 | 21/74 = 28.38% | 33/74 = 44.59% | 38/74 = 51.35% |

结论：纯时频图在干净样本上与复合图相同；轻噪声下降明显，重噪声反而比复合图更高，可能是复合图中的波形/频谱在重噪声下引入了额外干扰。

## 按传播条件

| 传播条件 | Qwen2-Audio | Qwen2.5-VL 复合图 | Qwen2.5-VL 纯时频图 |
| --- | ---: | ---: | ---: |
| Direct | 37/111 = 33.33% | 66/111 = 59.46% | 63/111 = 56.76% |
| Bellhop | 34/111 = 30.63% | 64/111 = 57.66% | 63/111 = 56.76% |

结论：这版评测里 direct 与 Bellhop 完全持平，说明当前问题主要不是多径，而是图像读数/任务表征。

## 关键错因

- 主频：全部 6 个错误都是 `250 Hz -> 500 Hz`，覆盖 clean/light/heavy 和 direct/Bellhop；说明即使加密刻度，低频端贴近 x 轴的位置仍容易被 VLM 上读一档。
- LFM：纯时频图 `36/36`，证明 VLM 对明显斜线轨迹的 zero-shot 识别非常强。
- 信号类型：所有 `LFM` 都正确，但 `CW` 只有 12/36，`FSK` 0/24，`BPSK` 0/30；模型倾向把非 LFM 也解释成 LFM 或 CW。
- FSK 阶数：整体仍是 12/24，说明“只看时频图 + 文字选择题”不足以让模型可靠区分 2FSK/4FSK。

## 初步判断

- 如果目标是测试“能不能看主频”，纯时频图比复合图更合适，但需要专门放大低频区或把 y 轴上限缩到任务相关范围。
- 如果目标是测试“信号类型能不能直接认出来”，不能只给时频图；BPSK 需要相位图/相位差分，FSK 需要频阶增强或局部放大。
- 当前 zero-shot 结论是：VLM 有很强的几何读图能力，但不是水声/调制信号专家；它会读斜率和粗频率，却不会稳定理解相位跳变与离散频阶。

## 建议下一步

1. 主频题改用任务自适应频率范围图，例如 `0-1000 Hz`、`0-3000 Hz`、`0-8000 Hz` 分档，而不是所有样本固定 `0-8000 Hz`。
2. 信号类型题改成多视图诊断输入：时频图 + 幅度谱 + 相位/瞬时频率，避免 BPSK/FSK 信息在单一图里不可见。
3. 对 250/500 Hz 单独生成低频放大图，验证错误是否来自视觉分辨率/坐标读数，而不是模型完全不懂主频。
4. 继续保持 zero-shot 探针，不进入微调；先把输入表示和题型拆清楚。
